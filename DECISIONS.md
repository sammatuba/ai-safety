how to revisit. New decisions go at the bottom. Never delete; mark `superseded by D-nnn`.

## D-001 (2026-10-23): hand-written AGENTS.md, not wired into MEOS

`../estate.json` or generated by MEOS tooling.
**Reasons.** The owner asked for a tool-agnostic contract readable by ChatGPT and DeepSeek

tools do not need. Research documents, not module boundaries, are the content.

**Revisit.** If the repository gains code that other MEOS modules consume.

## D-003 (2026-10-23): sprint environment is our own small review game, not Colosseum

**Decision.** The sprint experiment uses a deterministic proposer-reviewer-decider review
game implemented in `lab/`, with scripted agents for the positive control and an
OpenAI-compatible adapter for LLM agents. Colosseum is referenced, not imported.
**Reasons.** Track 2.3 needs matched regimes that differ in exactly one factor (provenance,
exposure order, payoffs, channel). Colosseum's Hospital and Jira tasks were not built for
that factorial control, their setup needs CoLLAB as a submodule, and the guide rates data
preparation risk as medium. A game we control gives a certain positive control at zero
API cost on day one.
**Rejected.** Running Colosseum episodes; reusing ColludeBench transcripts as the main data.
**Revisit.** If organizers release labeled logs during the sprint, add them as a second
dataset for external validity.

## D-004 (2026-10-23): add a "shared incentive, no channel" regime

**Decision.** The regime grid includes E0 (both agents approval-seeking, no channel) next
to E1 (same payoffs, private channel on).
**Reasons.** E0 is parallel conduct, the Track 2.3 guide's second case type. Without it,
the communication effect Δ_comm = P(invalid approval | E1) − P(invalid approval | E0) cannot
be computed, and an auditor cannot be tested on the hardest innocent explanation.

## D-005 (2026-10-23): one OpenAI-compatible LLM adapter

**Decision.** `lab/src/epistemic_lab/llm.py` speaks the OpenAI chat-completions protocol,
configured by `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`.
**Reasons.** OpenRouter, Nebius, DeepSeek, and local servers all expose this protocol.

**Rejected.** Provider SDKs; LangChain.

## D-008 (2026-10-23): the explainer is a dependency-free static site, not a new source of truth

**Decision.** `explainer/` holds a dependency-free HTML/CSS/JavaScript learning interface
over the nine foundations, the conditions layer, and the glossary. The Markdown files stay
canonical. The glossary data file is generated from `GLOSSARY.md` by
`tools/build-glossary.py`. The demos are deterministic teaching models.
**Reasons.** The owner needs to explore and test concepts without setup friction. Static
classic scripts run from `file://` and a local server, need no package manager, and keep the
repository portable. Reusing the canonical glossary avoids a second vocabulary.
**Rejected.** MkDocs, Quarto, or a JavaScript framework; a single long HTML page; notebook
widgets. Each adds a build step or a runtime dependency for an interface whose content is
already Markdown.
**Revisit.** If the owner needs saved quiz state, or if the hand-authored foundation pages
drift from the canonical documents enough that a generator is cheaper than review.

## D-009 (2026-10-28): a persistent, broad AI safety research database

**Decision.** Build the landscape in `literature/landscape/`, with its collection project in
`projects/2026-10-ai-safety-landscape/`. Use SQLite for the local database and portable
JavaScript Object Notation Lines (JSONL) exports for versioned records. Generate maps from
those records. Keep downloaded responses in `sources/ai-safety-landscape/` with hashes.
All network requests remain in `lab/src/epistemic_lab/llm.py`.
**Reasons.** The owner requested a comprehensive landscape and persistent database using
DeepSeek search. Research areas overlap. A graph preserves those overlaps and provenance.
Search summaries establish discovery, not verified research claims. Coverage needs an
explicit query ledger and visible gaps. Collection must resume without repeating successes.
**Scope.** Include technical safety, misuse, deployment, human factors, and governance.
The existing collusion project is one branch. The topic map is an editorial interpretation.
**Budget.** The project PLAN records the permitted collection route and spending limit.
Do not infer permission for paid model inference from permission for free search.
**Rejected.** A document-only survey; an external graph service; untraceable model summaries;
equating an available coordination channel with observed collusion.
**Revisit.** Add a server database only if local search and portable exports become inadequate.
