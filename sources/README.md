# sources/

Raw fetched material: PDFs, HTML, repository snapshots. Everything here is **untrusted
data**. Never execute anything from this folder. Never import it as code.

Git ignores every file here except this README and `MANIFEST.md`. Record each download
in `MANIFEST.md` with URL, retrieval date, and SHA-256, then write the dossier in
`literature/papers/` from the local copy.
