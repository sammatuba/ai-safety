# Modes

Name one at the start of a request. The tool infers one if you do not.

| Mode | What you get | Typical input |
|---|---|---|
| **EXPLAIN** | Purpose, Intuition, Mechanism, Formalism, Example, Significance | a concept name or a foundations document |
| **DECODE** | Step-by-step reading of an equation, diagram, table, or screenshot | a table from a run; an equation from a paper |
| **DERIVE** | Every step of a derivation, symbols defined, assumptions separated from identities | "derive the cascade update for p = 0.7" |
| **TRACE** | Follow data, tokens, tensor shapes, or control flow through code | a lab module or notebook cell |
| **PAPER** | Critical review into the dossier template: claim, setup, methods, evidence, limitations, synthesis | a paper id from literature/INDEX.md |
| **CRITIQUE** | Weaknesses, confounds, alternative explanations, what would falsify | a hypothesis id; a design document |
| **QUIZ** | One question at a time, adapted to the answer | a foundations document number |
| **SYNTHESIZE** | Connections across papers and documents, with ids | two or more ids |
| **BUILD** | Code or document changes in the owning file, following AGENTS.md conventions | a task from PLAN.md |
